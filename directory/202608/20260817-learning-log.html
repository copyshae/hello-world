20260817 另一台 Cursor 電腦安裝兩個視窗

換機不必從零做視窗：有 Cursor 就開 hello-world，說「裝習作台和習作批改」，桌面會生成兩個捷徑。

一｜另一台怎麼做

  1. 同一 Cursor 帳號登入（帶回 User Rules）。
  2. Clone copyshae/hello-world 到桌面（或已有就 git pull origin master）。
  3. Cursor 開啟該資料夾，對 Agent 說：裝習作台和習作批改。
  4. 雙擊 習作台.cmd、習作批改.vbs。
  5. 金鑰用密碼管理器還原到 MathGrading\gemini-api-key.txt，不要進 Git。
尚未 clone 時，PowerShell 可貼：irm https://raw.githubusercontent.com/copyshae/hello-world/master/scripts/bootstrap-desktop-apps.ps1 | iex

二｜倉庫裡加了什麼

  • scripts/bootstrap-desktop-apps.ps1：clone／pull 後呼叫一鍵安裝。
  • scripts/install-desktop-apps.ps1：同時裝兩個視窗，並把快捷詞複製到 %USERPROFILE%\.cursor\。
  • skill／規則：install-desktop-apps；說明頁 directory/apps/desktop-install.html。
  • .gitignore：排除 .env、金鑰、token。
