20260805 桌面習作台：掃描匯入與捷徑打不開

接 0804：桌面習作台接上掃描匯入夾，並修好捷徑開不起來。

一｜掃描匯入

  • 「處理掃描匯入」：把掃描匯入夾複製到「練習回傳」並標待回。
  • 補回班級資料匯出／匯入、已發→待回。

二｜捷徑打不開

  • 現象：習作台.vbs／習作台.cmd 開不起來（中文路徑編碼、舊 install 字串沒閉合）。
  • 作法：ASCII 安裝腳本、Bypass 執行原則、絕對路徑啟動器；改完關掉舊視窗再開。
