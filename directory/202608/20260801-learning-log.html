20260801 護眼提醒桌面程式與雙機

八月首篇：把用眼休息、點藥、百恩晴、益生菌、午餐與飲水做成可改時間／文案的桌面提醒；並讓另一台有 Cursor 的電腦同樣能裝、可選 OneDrive 同步設定。

一｜提醒內容（可在視窗內改）

  • 07:30：點眼藥水、服百恩晴、開始日間補水。
  • 07:30–17:00：用眼短／長休息、飲水（間隔可調）。
  • 12:00：午餐、點藥、喝水；另有晚餐、益生菌、睡前點藥時段。
  • 僅供個人提醒，用藥／點藥仍依醫師指示。

二｜桌面程式與踩坑

  • WinForms 大字介面：可新增／刪除／套用／試播／開始提醒；設定存 reminders.json。
  • 自動關閉改為必須按「知道了」，避免一閃而過。
  • 用 護眼提醒.vbs 隱藏啟動，避免黑色 PowerShell 視窗閃現。
  • 安裝目錄改英文 Desktop\EyeCareReminder；桌面捷徑路徑寫死，避免 %~dp0 指錯。
  • 私有庫勿用 raw.githubusercontent 下載；本機用 git checkout … -- scripts\… 取檔。

三｜另一台也有 Cursor

  • 兩台各自 git pull 同一分支後跑 install-eye-care-app-to-desktop.ps1。
  • 加 -UseOneDrive：時間／文案進 OneDrive\EyeCareReminder 同步；「已提醒過」狀態仍各機本機，互不干擾。
說明見倉庫 scripts/README-eye-care-multi-pc.md；分支 cursor/eye-care-reminders-433c。
