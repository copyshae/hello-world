20260802 掃描檔改名、轉正與頁序

把 SCAN 裡沒有中文檔名的 PDF，依內文日期與大要改名；橫式被存成直式要轉正；頁碼亂序要由小到大重排。規則已寫進 Cursor 通則。

一｜做了什麼

  • 主資料夾與備份層的掃描機檔名（SKM_）批次 OCR 改名。
  • 行政公告檔名補上主旨；不要文號、雲端編號。
  • 手寫／影印辨識得出關鍵詞才改；不行就維持「掃描文件」。
  • 橫式內容直式存檔：順時針轉 90° 後再命名。
  • 多頁 PDF 能讀到頁碼且順序反了才重排。
  • 之後再說「繼續」：先看有無新進 SKM_，有再跑同一套。

二｜掃描規則（摘要）

  • 檔名：YYYY-MM-DD_代表性名稱.pdf。
  • 日期：發文／公告／中華民國年月日；否則用修改時間或掃描檔名日時（不用複製當下的建立時間）。
  • 行政公告：日期_行政公告_主旨。
  • 重複檔用「一、二、十一」；檔名不寫學生姓名與成績個資。
  • 掃描本體不上 GitHub。
完整條文在 Cursor User Rule「掃描檔改名規則」，以及本機 .cursor/rules/scan-rename.mdc。腳本在 H:\工具軟體\。
