20260803 數學習作批改視窗程式

一人一檔批改、依程度自產數位練習（不用均一）、LINE／Classroom 發放與回傳循環；桌面捷徑「習作批改」。

一｜做了什麼

  • WinForms 視窗：載入標準答案 → 手動或請 Cursor 批 → 輸出註記 PDF。
  • 程度：跟上（再提升）／略落後／明顯落後／需補先備；先備可多次補齊（每次約 1 點、≤3 題）。
  • 不用均一：Cursor 產練習題＋自學指導＋YouTube 搜尋／影片連結；按鈕「自產練習說明」。
  • 發放：LINE 群公告；回傳用個別 LINE／Classroom／雲端；沒裝置才「無裝置列印包」。
  • 手寫板：放到「手寫匯入」→「手寫板匯入並批」→ 進練習回傳循環。
  • 安裝腳本建立 Desktop\MathGrading\ 各夾與桌面 習作批改.vbs。

二｜本機安裝

  • cd $env:USERPROFILE\Desktop\hello-world
  • git pull origin master
  • powershell -ExecutionPolicy Bypass -File .\scripts\install-math-homework-grader.ps1
  • pip install pypdf reportlab（輸出 PDF 需要）
  • 雙擊桌面 習作批改.vbs
主要檔：scripts/math-homework-grader-app.ps1、math_grade_make_note_pdf.py、install-math-homework-grader.ps1、README-math-homework-grader.md。工作夾：標準答案、輸入、輸出、數位練習、練習回傳、練習歷程、列印專用、手寫匯入、認知輸入、重謄補充。暫緩成長圖／儀表板；需要時從本日誌接續。

三｜供日後修正程式（務必對照）

實際執行檔在桌面 MathGradingApp\（習作批改.vbs 啟動），工作夾 Desktop\MathGrading\。hello-world 的 scripts\ 是安裝來源，重裝會覆蓋 App；改程式要兩邊同步，否則下次安裝會退回舊版。

  • 課本寫法：提示詞與存檔都要國中直式（全形＋－＝、中間……、右邊①、分數 a／b）。禁止 $$、\dfrac、\times、\cdots。PowerShell Convert-ToTextbookMath、Python to_textbook_math、規則 textbook-math-style.mdc。
  • 多班＋多次考試：座號會重複。檔名／輸出詞幹為 班級_考試_座號（例 101_小考第一次_00）。開檔先讓 Gemini 掃卷面班級、考試、座號 00～35 再改名。輸入可分子夾 輸入\701\。勿對詞幹做 int(sid) 去對原卷 PDF。
  • 各班聯繫：班級聯繫.txt（班級 = 發放群組 | 回傳方式）。數位練習拆 數位練習\{班級}\；LINE 文案標明貼哪一班群。
  • Gemini 寫入表單：回覆可能是 ### 1) 不是 ^1)；沒寫的題不要發明成「3 ?」。WinForms 多行框遇 Unix \n 會截斷（練習只剩標題）。要 Convert-ToWinFormsText、Get-GeminiSection、Convert-GeminiMarksToLines，註記框 MaxLength = 0。
  • 產出連動：改註記後 PDF、試卷含批閱、數位練習、LINE 包都要重產（Save-Current 呼叫 Invoke-MakePdf -MergeOriginal -DigitalPack）。原卷 PDF 被開啟時改寫 *-試卷含批閱-新.pdf。
  • 工具選擇視窗當掉：找不到 Point 的超載…引數計數: 3。PowerShell 把 Point(16, $y + 8) 拆成三參數；必須 Point(16, ($y + 8))。改腳本後要關掉批改視窗再開。
  • 說明.txt 被蓋：每次啟動 Ensure-WorkTree 會用 ps1 內範本覆寫工作夾說明，改說明要改腳本範本。
  • 機密：不要提交 gemini-api-key.txt、.env、settings.json（可含金鑰）。學生姓名不要進檔名與日誌。
