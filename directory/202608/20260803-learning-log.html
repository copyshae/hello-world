20260803 數學習作批改視窗程式

一人一檔批改、依程度自產數位練習（不用均一）、LINE／Classroom 發放與回傳循環；桌面捷徑「習作批改」。

一｜做了什麼

  • WinForms 視窗：載入標準答案 → 手動或請 Cursor 批 → 輸出註記 PDF。
  • 程度：跟上（再提升）／略落後／明顯落後／需補先備；先備可多次補齊（每次約 1 點、≤3 題）。
  • 不用均一：Cursor 產練習題＋自學指導＋YouTube 搜尋／影片連結；按鈕「自產練習說明」。
  • 發放：LINE 群公告；回傳用個別 LINE／Classroom／雲端；沒裝置才「無裝置列印包」。
  • 手寫板：放到「手寫匯入」→「手寫板匯入並批」→ 進練習回傳循環。
  • 安裝腳本建立 Desktop\MathGrading\ 各夾與桌面 習作批改.vbs。

二｜本機安裝

  • cd $env:USERPROFILE\Desktop\hello-world
  • git pull origin master
  • powershell -ExecutionPolicy Bypass -File .\scripts\install-math-homework-grader.ps1
  • pip install pypdf reportlab（輸出 PDF 需要）
  • 雙擊桌面 習作批改.vbs
主要檔：scripts/math-homework-grader-app.ps1、math_grade_make_note_pdf.py、install-math-homework-grader.ps1、README-math-homework-grader.md。工作夾：標準答案、輸入、輸出、數位練習、練習回傳、練習歷程、列印專用、手寫匯入、認知輸入、重謄補充。暫緩成長圖／儀表板；需要時從本日誌接續。
