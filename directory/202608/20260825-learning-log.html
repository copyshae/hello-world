20260825 太陽盛德導師歌曲連播 PWA

接日誌 0824 弟子規 41 集。本日新增太陽盛德導師歌曲連播手機 PWA：依天圓文化曲庫自動排播放順序，可加入主畫面離線快取。

手機立刻可開（免開電腦）：
https://copyshae.github.io/-/directory/202608/20260825-learning-log.html
正式 hello-world： https://copyshae.github.io/hello-world/directory/202608/20260825-learning-log.html

一｜入口

  • 主版：https://copyshae.github.io/-/taiyang-music/
  • 分享／加入主畫面：https://copyshae.github.io/-/taiyang-music/share.html
  • hello-world 鏡像：https://copyshae.github.io/hello-world/directory/apps/taiyang-music/
  • 來源：docs/taiyang-music/（曲庫 catalog.json）

二｜播放順序

  • ① 〈注入彩虹〉×3 → ② 〈富有〉×3 → ③ 導師親唱各×1 → ④ 其他演唱者各×1。
  • 分類欄位 performer：master（導師親唱）或 other（其他演唱者）；App 可篩選。

三｜曲庫更新

  • scripts/build-taiyang-catalog.py 以 yt-dlp 搜尋 YouTube 更新曲庫。
  • App 內「更新曲庫」；每週一 GitHub Actions（update-taiyang-catalog.yml）自動更新。
