20260813 批閱輸出改國中課本形式

接 0812：自學練習像 Markdown／LaTeX，國中生不好讀。之後所有輸出比照課本直式。

  • 通則：【題號】【摘要】【診斷】【程度】【建議】【自學練習】。
  • 練習本體「一、先看這裡 → 二、影片 → 三、練習 → 四、解答」；禁止 ####／LaTeX／$$。
  • 下載練習 HTML 用標楷體風；「整理成課本格式」可清殘留 Markdown。
  • 習作台群發／回傳文案同步一～四步驟。
全形＋－＝、中間……、右邊①、分數 a／b 仍以 20260803「供日後修正程式」為準。
