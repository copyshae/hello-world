20260725 Visio 一步檢查點與對色指令

昨日主線：檔案級檢查點讓改圖可穩定回復／往前；戶外白縫補色後，收斂出「跟樣色同色」才對得準的指令方式。

一｜今日核心目標

  • Visio Undo 不可靠 → 用整份 .vsd 檢查點做 save／back／forward。
  • 114 掃地圖繼續修：學年 115、紅框年級底色、戶外 101～110 白縫補滿融合。
  • 訂出對色指令：以選取或色樣圖為準，勿盲調「再深一點」。

二｜一步檢查點（可回復／往前）

項目位置／用法
腳本 MyKnowledgeBase\_visio_work\visio_step.py：save／back／forward／list／goto N
一鍵 桌面 visio一步.ps1：存檔／回復／往前／列表

工作檔 桌面\114學年掃地區域分配圖1140808_可編修.vsd
  • 改前：save 改XXX前；確認後：save 改XXX後。
  • 使用者說「回復／往前」用腳本，勿狂按 Visio Undo。
  • Skill visio-school-map 已寫入「一步檢查點」節。

三｜戶外白縫與學年

  • 標題／右側學年數字：114 → 115。
  • 戶外白縫相關 Shape 例：255／256／257，遮罩 4716；去框線、補滿。
  • AccentColor4 階梯（由淺到深）曾試過：tint 80→60→40→20→純色→shade…；盲調難對上周圍。

四｜怎麼下指令才對得上色

指令效果
Visio 點選正確格 →「已選取，跟選取同色」 最穩：複製該 Shape 的 Fill 公式
貼色塊圖 →「跟這同色」 從圖取 RGB 後套上（例 RGB(183,221,232)＝AccentColor4 60%）
「再深一點／繼續／深 N 階」 只能一階一階試，容易過深或過淺
可貼提示詞：
「紅框白塊要跟周圍同色。先列出旁 2～3 個有填色 Shape ID；我點選樣色後，複製該格 Fill 塗上並補滿融合。不要自己猜深淺。」

五｜之後約定（精簡）

  1. 一次一處：截圖紅框或使用者點選。
  2. 對色先指定樣色來源（選取／色樣），再寫入。
  3. 每步進檢查點；回復用腳本。
  4. 確認 ActiveDocument 路徑（可編修 vs 複製）。
