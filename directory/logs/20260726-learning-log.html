20260726 多檔合併請假證明 PDF

今日主線：把公文 PDF、批核紀錄 PDF、實施計畫 DOCX 合成一份請假證明；Word COM 卡住後改走 LibreOffice＋pypdf。

一｜產出

  • 檔名：115學年健康檢查員增能研習請假證明.pdf（本機衛生組資料夾，不上雲）。
  • 頁序：公文 2 頁 → 批核紀錄 1 頁 → 實施計畫（DOCX 轉 PDF）1 頁，共 4 頁。

二｜做法（可重跑）

  1. 三檔先複製到 ASCII 暫存目錄（避免中文路徑在指令列亂碼）。
  2. DOCX→PDF：soffice --headless --convert-to pdf（LibreOffice）。
  3. 合併：Python pypdf.PdfWriter 依序加頁後寫出。
  4. 再複製回原資料夾並用目標中文檔名。
Word ExportAsFixedFormat 可能無回應；有 LibreOffice 時優先 headless 轉檔較穩。

三｜踩過的坑

現象處理
PowerShell／Python 夾帶中文路徑變亂碼 暫存用英文檔名；最後再用 .NET File.Copy 寫回中文路徑
Word COM SaveAs([ref]…) 型別錯誤／整段卡住 改 LibreOffice；卡住時結束 WINWORD 行程
soffice 第一次看似沒產出 用 Start-Process -Wait 並看 stdout；確認產生 3_plan.pdf 再 merge

四｜之後可複用指令骨架

  • 轉檔：soffice --headless --norestore --convert-to pdf --outdir <tmpdir> <plan.docx>
  • 合併：讀多個 PDF → PdfWriter.add_page → write
