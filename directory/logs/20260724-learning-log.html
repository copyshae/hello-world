20260724 Visio 掃地圖精確改色與一步檢查點

今日主線：114 學年掃地區域圖以 Visio COM 改底色／圖層／門口 110；從「整圖掃射」踩坑，收斂成一次一處、可檔案級回復／往前的檢查點流程。

一｜今日核心目標

  • 自強樓紅框文字方塊依年級補底色（1xx 藍／2xx 橘／3xx 綠）。
  • 門口、中正路二段、戶外 110 對照原檔補回填色與字。
  • 解決「Undo 不可靠」：每步存檢查點，可穩定回復或往前。
  • 訂出精確改圖約定，避免再耗一天在鄰近形狀誤改。

二｜踩坑與補救

問題結果／補救
COM 整圖 SendToBack／改透明度 常改錯鄰近物件；改為一次一處、先報 Shape ID 再改
Visio 難手動編輯 恢復 Interactive=True；關掉輔助唯讀檔；必要時另存「請用這份手動改」
存檔後 Undo 失效 改用檔案級檢查點（整份 .vsd 快照）做回復／往前
多開 Visio／多檔 用 GetObject(path)；注意「複製 (1)」與主檔是不同路徑

三｜年級底色慣例（自強樓紅框）

班號底色備註
1xx（如 101）淡藍例 RGB(219,238,243)／AccentColor4
2xx（如 207、210、205）橘／桃例 AccentColor5；底色應在框線內，勿蓋線
3xx（如 304、305）淡綠對齊同欄已上色文字方塊
缺底色時優先開 FillPattern=1 並對齊同輩 Shape 的填色公式；若原檔有窄條底色（如直書 205），對照原檔幾何縮在框內。

四｜一步檢查點（可回復／往前）

工作區：知識庫 MyKnowledgeBase\_visio_work\；檢查點在桌面（大檔不進 Git）。

項目位置／用法
腳本 visio_step.py：save／back／forward／list／goto N
一鍵 桌面 visio一步.ps1：存檔／回復／往前／列表
檢查點目錄 桌面\Visio檢查點_114掃地\（含 index.json）
工作檔 桌面\…1140808_可編修.vsd（若開「複製 (1)」則改的是複本）
  • 改圖前：save 改XXX前；確認後：save 改XXX後。
  • 使用者說「回復／往前」用腳本，勿狂按 Visio Undo。
  • Skill visio-school-map 已寫入「一步檢查點」節；提示詞見 prompts/visio-edit-prompt.md。

五｜其他進度摘要

  • 左檔曾同步「已更新班號」；覆蓋前備份留在桌面。
  • 門口／中正路二段／戶外 110：對照原檔補填色與字色。
  • 戶外淡藍小塊：對齊外圍色、必要時等大淡藍遮罩覆蓋；注意圖層與「選錯 Shape ID」。

六｜之後約定（精簡）

  1. 一次只改一個明確目標（截圖框選或使用者點選）。
  2. 先報 Shape ID／現況→目標，再寫入。
  3. 禁止整圖層級掃射；底色小塊以手動為主、腳本為輔。
  4. 收工確認可點選、拖曳、改填色；重要步驟進檢查點。

七｜最後備註：參考圖示修圖

後續修 Visio 掃地圖時，以畫面圖示／截圖紅框為準：先對齊使用者標出的位置與鄰近色塊／圖層，再改 Shape；勿只憑記憶或猜 ID。底色、遮罩、SendToBack 等都應對照當下可見的參考圖示確認。
