20260730 E 碟整理與 Google 備份

今日主線：外接碟 E: 結構整理入庫腳本化；Google Drive（G:）備份到 E:；Google 相簿改走 Takeout 打包下載。

一｜E: 目錄整理

  • 公司資料併入學校後清空公司殼層；再把學校內容分到既有歸檔／超級生命密碼等兄弟目錄。
  • 不重建 E:\私人：原私人子資料夾維持在 E: 根目錄。
  • 衝突檔名去掉 _fromE_／_fromPrivate_；未命名檔依 0717 規則改名；空的搬移日誌資料夾清掉。
  • PowerShell 5.1 腳本需 UTF-8 BOM；本機執行前先確認 scripts\ 已 git pull 到正確分支。

二｜Google Drive → E:

  • 來源：桌面版掛載的 G:（常見 我的雲端硬碟／My Drive）。
  • 目的：E:\google_drive（本機亦見 E:\GOOGLE_DRIVE）。
  • 腳本 backup-google-drive-to-e.ps1：預設 dry-run，加 -Execute 才用 robocopy 複製；不加鏡像刪除。
  • 串流模式可能拷不到未下載檔；大備份可重跑續傳。

三｜Google 相簿 → E:\GOOGLE相簿

  • 相簿不是 Drive，不能直接從 G: 複製。
  • 曾試 rclone（免安裝版放桌面 hello-world-tools\tools\rclone）；需先完成 gphotos 授權，否則會報找不到 remote。
  • 授權不順時改用 Google Takeout：只勾「Google 相簿」，等待打包郵件後下載 zip，解壓到 E:\GOOGLE相簿。
雲端 agent 讀不到本機 E:／G:；實際複製與授權都必須在本機 PowerShell 完成。本機若缺腳本，可從 GitHub raw 下載到 Desktop\hello-world-tools。

四｜入庫

  • 相關腳本與說明收在 hello-world 的 scripts\（含 Drive 備份、相簿 bootstrap／rclone、學校清空等）。
  • 變更走功能分支與 PR，學習日誌本篇獨立推送。
