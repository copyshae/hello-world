20260819 連接 GitHub 遠端與工作日誌推送

今日主線：在 Cloud Agent 環境中確認並連接 GitHub 遠端，將工作日誌推送到兩個倉庫。

一｜確認倉庫遠端連線

  • Cloud Agent 環境內 git remote 可能尚未設定，需手動補上。
  • 使用 gh repo view --json nameWithOwner,url 可快速查出目前倉庫對應的 GitHub 位址。
  • 確認 copyshae/- 倉庫遠端為 https://github.com/copyshae/-。
  • 以 git remote set-url origin <url> 設定或修正遠端。

二｜推送流程驗證

  • 推送前先 git fetch origin main 確認網路與憑證皆正常。
  • 建立功能分支、commit、push 三步驟完成日誌更新。
  • 在 copyshae/- 倉庫的 工作日誌.md 補記今日內容。

三｜跨倉庫學習日誌同步

  • copyshae/- 倉庫：以 Markdown 格式記錄於 工作日誌.md。
  • copyshae/hello-world 倉庫：以 HTML 頁面記錄於 directory/logs/，可在 GitHub Pages 上瀏覽。
  • 兩邊日誌各自獨立維護，內容可交叉對照。
學習重點：gh CLI 已預先授權，可快速查詢倉庫資訊；Cloud Agent 中操作 git 與本機相同，但要注意 remote 設定。
