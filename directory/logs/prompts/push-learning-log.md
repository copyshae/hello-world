# 快捷提示詞｜推學習日誌

之後不必打長句。在 Cursor 對話直接輸入：

```
推日誌
```

其他同義：

| 短語 | 用途 |
|------|------|
| `推日誌` | 預設：今日日期、本對話工作大要 |
| `上日誌` | 同上 |
| `收工推日誌` | 收工時用 |
| `推日誌 0726` | 指定月日（當年） |
| `工作大要推 hello-world` | 完整說法 |

會寫入並推送：`https://github.com/copyshae/hello-world` → `directory/logs/`。

本機 skill：`%USERPROFILE%\.cursor\skills\push-learning-log\SKILL.md`  
本機規則：`%USERPROFILE%\.cursor\rules\push-learning-log.mdc`
