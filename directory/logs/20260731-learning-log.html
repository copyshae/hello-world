20260731 Google Drive／相簿備份到 E:

今日主線：把 Google 雲端資料落到外接碟——Drive 從 G: 複製；相簿用 Takeout（rclone 授權備援）。

一｜Google Drive（G: → E:）

  • 桌面版 Google Drive 掛載為 G:；常見根目錄為「我的雲端硬碟」或 My Drive。
  • 備份目的地：E:\google_drive（本機資料夾名也可能是 GOOGLE_DRIVE）。
  • 腳本 scripts/backup-google-drive-to-e.ps1：先預覽，再加 -Execute 以 robocopy 複製；預設不鏡像刪除。
  • 串流模式可能拷不到尚未下載的檔；可改鏡像硬碟或重跑續傳。

二｜Google 相簿（→ E:\GOOGLE相簿）

  • 相簿與 Drive 分開，不能只靠複製 G:。
  • 正式路線：Google Takeout 只勾「Google 相簿」→ 等郵件 → 下載 zip → 解壓到 E:\GOOGLE相簿。
  • 備援：本機免安裝 rclone（hello-world-tools\tools\rclone），需先建立 remote gphotos 並完成瀏覽器授權，才能 copy。
本機若缺倉庫內腳本，可從 GitHub raw 抓到桌面 hello-world-tools；雲端對話無法直接讀寫 E:／G:。

三｜入庫與工具

  • backup-google-drive-to-e.ps1、bootstrap-google-photos-to-e.ps1、download-google-photos-to-e.ps1 及對應 README。
  • PowerShell 5.1 腳本維持 UTF-8 BOM，避免中文路徑亂碼。
