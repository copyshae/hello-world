20260728 學習日誌快捷詞全域化

今日主線：把 hello-world 學習日誌相關操作整理成全域快捷詞，讓任何專案都能直接推工作大要、開日誌列表、開學習日誌首頁，並支援換機安裝。

一｜這次加了哪些快捷詞

短語用途
推日誌／上日誌／收工推日誌 把本對話剛完成的工作大要寫進 hello-world 學習日誌並推上 GitHub
連日誌／連上學習日誌／開日誌 開啟當月學習日誌列表：/directory/logs/
日誌首頁／學習日誌首頁／開首頁 開啟學習日誌首頁：/directory/

二｜全專案、跨電腦的做法

  • 正式定義寫進 hello-world 倉庫：.cursor/skills/push-learning-log/SKILL.md、.cursor/rules/push-learning-log.mdc。
  • 另做一支安裝腳本：install-push-log-shortcut.ps1。
  • 每台電腦只要跑一次安裝腳本，就會複製到使用者層級的 %USERPROFILE%\.cursor\skills\ 與 %USERPROFILE%\.cursor\rules\。

三｜換機時怎麼裝

  1. git clone 或 git pull hello-world。
  2. 在倉庫根目錄執行：powershell -ExecutionPolicy Bypass -File .\install-push-log-shortcut.ps1
  3. 重新開 Cursor 對話後，在任何專案直接輸入快捷詞即可。
之後若倉庫裡的快捷詞規則更新，另一台電腦再跑一次安裝腳本即可同步。

四｜這次收斂出的規則

  • 學習日誌內容只寫工作大要，不寫密碼、vault、個資、學生名冊。
  • 日期可指定，例如 推日誌 0728。
  • Git 沒有設定使用者時，用環境變數帶入 copyshae 與 GitHub noreply 信箱，不改全域 git config。
