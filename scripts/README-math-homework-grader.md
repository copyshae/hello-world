# 數學習作／試卷批改：一人一檔、一檔一檔來

## 開始時批閱方式

1. **載入正確答案**（可多檔）→ 供對照  
2. 選擇批閱方式：
   - **自己對照批**：開啟答案＋學生卷，你填 ✓✗?  
   - **請 Cursor 直接批閱／手寫加強**：複製提示、開檔 → 到 Cursor 貼上並附檔  
   - **請 Gemini 直接批閱／手寫加強**：複製提示、開檔，並開啟 [Gemini](https://gemini.google.com/app) → 貼上並上傳學生卷（用你的 Google 帳號即可，不必 API）

然後仍是 **一人一檔、一檔一檔**：開始批此生 → 輸出PDF → 下一位未批。

### 用 Gemini 自動批（免手動貼檔｜建議試發座號 00）
1. 到 https://aistudio.google.com/apikey 用 Google 帳號建立 **API key**（與網頁 Gemini Pro 訂閱分開；免費額度通常夠試發）  
2. 習作批改 → **Gemini金鑰** → 貼上儲存（存在本機 `MathGrading\gemini-api-key.txt`，不上傳 GitHub）  
3. 批閱方式選 **「請 Gemini 自動批閱（API）」** 或 **「自動手寫加強」**  
4. 「開始批此生」→ 程式自動送出學生卷＋標準答案＋提示 → 回覆填入右側並存 `輸出\00-Gemini回覆.md`  
5. 過目後「輸出此生PDF」

網頁手動貼檔仍可用（「請 Gemini 網頁批閱」），但不自動。

### 用 Gemini 網頁批（手動）
1. 批閱方式選「請 Gemini 網頁…」→「開始批此生」  
2. 瀏覽器開 Gemini → `Ctrl+V` 貼提示 → **上傳** 試卷  
3. 回覆貼回程式右側 →「輸出此生PDF」

全班經 AI（Cursor 或 Gemini）＋老師反覆確認後，按 **全班學習總表** 產出給導師／家長：
- `全班學習狀況總表.pdf` / `.md` / `.csv`
- 含程度分布、常見課題、需關注座號、逐座號一覽（以座號、不含姓名）

每位輸出 PDF／註記末段固定含：
- **個別診斷結果**（弱點、是否跟上）
- **程度**：跟上／略落後／明顯落後／需補先備
- **練習依程度**：
  - **跟上（好的學生再提升）**：少鞏固 → 靈活 → **再提升挑戰（必做）** → 超前伸展（選做）；禁止只改數字的簡單重複題
  - 略落後／明顯落後／需補先備：**多次補齊**（每次 1 點、少題）→ 先有成就 → **漸次跟上**（勿一次補完、勿連催）
- **練習發放（省紙）**：
  - **預設**：Cursor／Gemini／本程式**自動產練習題＋自學指導＋建議影片連結**（不用均一）
  - 發：LINE 班級群組；回：LINE 個別傳老師
  - 或 Classroom／雲端；沒裝置才列印包
- **練習回傳循環**：回傳 PDF／圖 → 再自動產下一輪練習／指導／影片 → 歷程看進步

### 練習怎麼來（不用均一）
1. 「請 Cursor／Gemini 直接批閱」→ 一次產出診斷、程度、指導、練習、解答、影片搜尋連結  
2. 貼回後「輸出此生PDF」→ `數位練習\` 給學生  
3. 回傳後再批 → 依問題點再產下一輪（多次補齊／再提升）  
4. 影片優先用 YouTube 搜尋頁；有把握才貼具體影片 URL

## 資料夾

```
Desktop\MathGrading\
  標準答案\
  輸入\           ← 00.pdf、05.pdf（一人一檔；試發用 00）
  輸出\           ← 00-註記.md、00-Gemini提示.txt、批閱 PDF
  數位練習\       ← 手機 HTML／TXT、LINE訊息、歷程頁
  手寫匯入\       ← 手寫板／平板匯出圖或 PDF（一鍵「手寫板匯入並批」）
  練習回傳\       ← 學生回傳 05-R01.jpg／.pdf（供抓取批閱）
  練習歷程\       ← 分數進步、每次回饋、待批清單
  列印專用\       ← 需列印座號.txt ＋ 僅無裝置者之練習 PDF
  認知輸入\       ← 老師確認潦草字
  重謄補充\       ← 重謄後再掃的 PDF
```

### 手寫板即時批閱
1. 寫完存到 `手寫匯入\`（或改成 OneNote／繪圖軟體匯出夾）  
2. 左側選座號 → **手寫板匯入並批**  
3. 自動進 `練習回傳\`、複製批閱提示並開檔 → 貼到 Cursor 或 Gemini 批  
4. 結果貼回「練習回傳循環」產下一輪練習／指導／影片
